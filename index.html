是更聪明的招聘流程

把「打开简历 → 判断匹配 → 复制话术 → 点击打招呼」这些重复动作，交给插件按你的规则自动完成。

关键词双向筛选

为每个岗位设置「简历筛选关键词」和「黑名单关键词」，符合要求的候选人才进入下一步，从源头上减少无效沟通。

Yili AIAgent 分析

接入 Yili AIAgent，自动分析候选人是否匹配岗位，并给出匹配结论与理由。AI 只是你的辅助，决策权始终在你。

一键批量打招呼

在「推荐牛人」页一键启动，插件按设定节奏自动滚动、筛选、打招呼，中途随时停止，日志实时可见。

求简历 / 拒简历话术

自定义「求简历话术」和「拒简历话术」，也能在沟通页一键批量求简历、一键简历回传，减少重复打字。

数据本地服务器保存

岗位、筛选条件、运行记录均保存在本地服务器，不经过第三方商业服务器，数据安全可控。

节奏拟人可追踪

控制滚动间隔与操作节奏，避免机械式点击；每次运行都有控制台日志，处理数量、筛选结果一目了然。

常见问题

使用前你可能想知道这些。

请确认你当前打开的是 BOSS直聘（www.zhipin.com）页面，并且处于「推荐牛人」或沟通页。插件只在这些页面生效。如果提示登录，请使用管理员分配的账号登录。
插件内置节奏控制与随机间隔，模拟人工操作；可自由设置每次打招呼上限（1–200）并随时停止。但由于 BOSS直聘 对插件、外挂等辅助工具的治理要求，仍可能触发网页端临时封号 1 天——APP 使用不受影响，次日自动恢复。建议合理控制频率，避免短时高频操作。
岗位、筛选条件、运行记录全部保存在本地服务器中，不上传浏览器之外的第三方商业服务器。开启 AI 分析后，简历分析请求由 Yili AIAgent 处理。
支持所有基于 Chromium 的桌面浏览器，如 Chrome、Edge、360 极速浏览器等。需要 Manifest V3 支持，暂不支持 Firefox 和移动端浏览器。Windows 与 macOS 均可使用。
如果系统自带解压工具出现乱码，建议使用 7-Zip 或 macOS 自带「归档实用工具」解压。解压后应看到一个名为「招聘速聊助手」的文件夹，里面包含 manifest.json。
